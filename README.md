## 🚀 The Daily Goal

🟢 **1 problem, every single day**
🟢 Understand the pattern, don't memorise the answer
🟢 Brute force first, optimise second
🟢 30-minute timebox — then editorial, and re-solve it a week later
🟢 Log the misses honestly

Small daily reps beat weekend marathons. Every time. ⏳

---

## 🧠 My Approach

```
1️⃣  Restate the problem in my own words
2️⃣  Write the brute force — say its complexity out loud
3️⃣  Ask: what am I computing twice?
4️⃣  Kill that with the right data structure
5️⃣  Dry-run a small input BEFORE submitting
```

Step 3 is the whole game. Every optimisation is an answer to that question. 💡
